# نقش‌خوان – نسخه آزمایشی ۰.۱

این بسته سورس اندروید به‌همراه گردش‌کار ساخت ابری APK است.

## امکانات فعلی
- انتخاب و پخش کلیپ از حافظه گوشی
- کنترل پخش و مکث
- ضبط صدای دوبله با میکروفون
- ذخیره فایل صدای دوبله با فرمت M4A در پوشه اختصاصی برنامه
- بدون حساب کاربری و بدون سرور؛ انتخاب کلیپ و ضبط پس از نصب آفلاین است

## محدودیت‌های نسخه ۰.۱
- صدای دوبله هنوز روی تصویر/صدای فیلم میکس نمی‌شود.
- خروجی MP4 نهایی هنوز ساخته نمی‌شود.
- تشخیص خودکار دیالوگ، جداسازی صدای شخصیت‌ها و هوش مصنوعی هنوز در این نسخه نیست.

## ساخت APK با گوشی، بدون نصب Android Studio
۱. در مرورگر گوشی وارد GitHub شو و یک حساب بساز/وارد شو.
۲. یک Repository جدید با نام `NaghshKhan` بساز و آن را Public قرار بده.
۳. فایل‌های داخل پوشه `NaghshKhan` این بسته را در ریشه مخزن بارگذاری کن؛ خود فایل ZIP را به‌عنوان یک فایل تنها بارگذاری نکن. پوشه‌ها و فایل `.github/workflows/build-apk.yml` نیز باید حفظ شوند.
۴. پس از بارگذاری، در مخزن به زبانه **Actions** برو.
۵. گردش‌کار **Build NaghshKhan APK** را انتخاب و **Run workflow** را بزن (اگر با push خودکار شروع نشده باشد).
۶. پس از پایان موفق، اجرای workflow را باز کن و از بخش **Artifacts** فایل `NaghshKhan-debug-apk` را دانلود کن.
۷. ZIP آرتیفکت را در گوشی باز کن و `app-debug.apk` را نصب کن. اگر اندروید اجازه خواست، نصب از همین مرورگر/مدیریت فایل را مجاز کن.

## نکته مهم
- ساخت ابری نیازمند اینترنت و حساب GitHub است و برای مخزن عمومی، اجرای GitHub Actions در محدوده رایگان GitHub Free معمولاً قابل استفاده است؛ سهمیه و شرایط GitHub ممکن است تغییر کند.
- فایل APK این گردش‌کار، نسخه Debug برای آزمایش شخصی است، نه نسخه انتشار فروشگاهی.
- اولین بار دانلود ابزارهای ساخت و کتابخانه‌ها اینترنت لازم دارد؛ خود اپ پس از نصب برای انتخاب کلیپ و ضبط صدا به اینترنت نیاز ندارد.
